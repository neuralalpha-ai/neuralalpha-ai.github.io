# プライバシーポリシー（会社リスト補完）

最終更新：2026年10月27日

NeuralAlpha（以下「当方」）は、Googleスプレッドシート用アドオン「会社リスト補完」（以下「本アドオン」）における情報の取り扱いを次のとおり定めます。

## 1. 本アドオンがアクセスするデータ
本アドオンが要求する権限は次の3つです。
- `spreadsheets.currentonly`：本アドオンを使用中のスプレッドシート**のみ**の読み書き
- `script.container.ui`：サイドバーの表示
- `script.external_request`：外部サービス（下記）への接続

本アドオンは、利用者が指定した列の**会社名**と、任意で指定した**都道府県・住所**のセルを読み取り、結果を指定された列に書き込みます。それ以外のセル、他のファイル、Gmail、Googleドライブ等にはアクセスしません。

## 2. 外部に送信する情報
- **Gビズインフォ（経済産業省）のAPI**：法人を検索するため、会社名（および法人番号）を送信します。住所のセルの値は送信せず、本アドオン内で照合にのみ使います。

## 3. 保存する情報
- 当方は、利用者のスプレッドシートの内容を当方のサーバーに保存しません（アドオン版では当方はサーバーを運用していません。コピー版の中継については8のとおりです）。
- 同じ問い合わせを繰り返さないため、Gビズインフォの検索結果（公開されている法人情報）をGoogle Apps Scriptのキャッシュに最大6時間保存します。
- 月ごとの利用行数を、Google Apps Scriptのユーザープロパティ（利用者ごとの設定領域）に保存します。

## 4. 第三者提供・販売
当方は、利用者のデータを販売せず、広告目的で利用せず、上記2および8以外の第三者に提供しません。

## 5. Google API サービスのユーザーデータに関する方針
本アドオンによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)（Limited Use の要件を含む）に従います。

## 6. お問い合わせ
neuralalpha-support@googlegroups.com（メール）または [GitHub Issues](https://github.com/neuralalpha-ai/neuralalpha-ai.github.io/issues)

## 7. 改定
本ポリシーを改定する場合は、このページで告知します。

## 8. コピーして使う版について
スプレッドシートごとコピーして使う版（以下「コピー版」）では、次の点がアドオン版と異なります。
- 会社名・法人番号は、Gビズインフォに直接ではなく、当方が運用する中継（Google Apps Script のウェブアプリ）を通して送信されます。中継はGビズインフォへの問い合わせのためだけに使い、送られた会社名・法人番号を記録しません。同じ問い合わせを繰り返さないため、Gビズインフォの検索結果（公開されている法人情報）を最大6時間キャッシュします。
- 利用回数の上限を管理するため、利用者ごとにランダムな匿名ID（名前・メールアドレス等を含みません）を作り、問い合わせのたびに中継へ送ります。当方が保存するのは匿名IDごとの月の利用回数だけで、翌月に消去します。
- 都道府県・住所のセルの値は、アドオン版と同じく送信しません。
